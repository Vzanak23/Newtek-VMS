3. Client Management

3.1 Purpose

The Client module manages platform information in the system. In this application, "Client" refers to different vehicle platforms or product lines (e.g., Cummins). Each client represents a distinct manufacturing platform with its own set of parts, ferrules, and quality control procedures.

3.2 Viewing Clients

  1. Click on Client from the navigation menu
  2. View the list of clients in a table format

The client table displays the following information:

  • Sr. No.: Serial number for reference
  • Client Name: Name of the platform (e.g., Cummins)
  • Edit: Option to modify client details
  • Delete: Option to remove the client

3.3 Adding a New Client

  1. Click the + (Plus) button in the top-left corner
  2. Enter the required client information in the form
  3. Fill in all mandatory fields
  4. Click Save to add the client to the system

3.4 Editing a Client

  1. Locate the client you want to edit in the table
  2. Click the Edit button in the corresponding row
  3. Modify the client details as needed
  4. Click Save to update the information
  5. Click Cancel to discard changes

3.5 Deleting a Client

Critical Warning

Deleting a client (platform) is a critical operation that cannot be undone. Please read the Important Cautions section before proceeding with client deletion.

  1. Locate the client you want to delete
  2. Click the Delete button (displayed in red)
  3. Read the confirmation dialog carefully
  4. Confirm the deletion only if you are certain

3.6 Search Functionality

  1. Use the search box at the top-right of the screen
  2. Type the client name or keyword
  3. Click the Search button to filter results
  4. Click the × icon to clear the search and show all clients

Best Practice

Set up all clients (platforms) at the beginning of your system configuration. This provides the foundation for all other data in the system.

4. Parts Management

4.1 Purpose

The Parts module manages detailed information about ferrule parts including part numbers, names, specifications, and associated models. Parts are the core components that undergo quality control inspection.

4.2 Understanding Parts Data Structure

Parts in the system contain comprehensive information including:

  • Part Number (e.g., A072C004)
  • Part Name (e.g., Shakti CT Big)
  • Ratio (e.g., 1000/5A)
  • Burden (e.g., burden1)
  • Label Type (e.g., Rectangular Type 71X19)
  • Ferrules count and configuration
  • Ferrule Direction (e.g., S1,S2,S1,S2,S1,S2,S1,U,U,S2,U,S1)
  • Image path for visual reference
  • Severity level
  • Attributes and highlights
  • Location information
  • OCR operations

4.3 Viewing Parts (Ferrules View)

  1. Click on Parts from the navigation menu
  2. Select a Client from the dropdown at the top
  3. View parts in the simplified table showing:
    • Part No
    • Part Name
    • Update option (green link)
    • Edit option
    • Delete option

4.4 Viewing Complete Parts Details

When viewing the full parts list from the main navigation, you'll see comprehensive information:

Ratio: 1000/5A

Label Type: Rectangular Type (71X19)

4.5 Adding a New Part

  3. Fill in the required information:
    • Part Number: Enter unique part identifier

    • Highlight: Set highlight properties
    • Location: Physical location information
    • OCR Operation: Optical character recognition settings

4.6 Duplicate Part Numbers

5. Ferrules Management

5.1 Purpose

The Ferrules module manages information about ferrule configurations. Ferrules are connection points or terminals used in electrical components that undergo quality control inspection. Each ferrule has specific characteristics and is associated with particular model codes.

5.2 Understanding Ferrules

Ferrules in the system represent:

  • Specific connection terminals on parts
  • Numbered identification (e.g., Ferrule No: 12)
  • Named configurations (e.g., Shakti CT Big)
  • Associations with specific parts and models

5.3 Viewing Ferrules

  1. Click on Ferrules from the navigation menu
  2. Select a Client from the dropdown menu
  3. View ferrule information in the data table
  4. Review ferrule numbers, names, and associated data

5.4 Adding Ferrules

  1. Select the client platform from the dropdown
  2. Click the + (Plus) button in the top-left corner
  3. Enter required ferrule information:
    • Ferrule Name: Descriptive name (e.g., Shakti CT Big)
    • Ferrule Number: Numeric identifier (e.g., 12)
    • Model Code Length: Associated model code specifications
  4. Click Save to create the ferrule

5.5 Editing Ferrules

  1. Find the ferrule in the data table
  2. Click the Edit button for that ferrule
  3. Modify details as needed:
    • Update ferrule name
    • Change ferrule number
    • Adjust model code length
  4. Save changes to update the ferrule

5.6 Deleting Ferrules

  1. Locate the ferrule you want to delete
  2. Click the Delete button for that specific ferrule
  3. Confirm the deletion when prompted

Note on Ferrule Deletion

Check ferrule connections before deletion to ensure you don't remove ferrules that are actively used in quality control processes.

5.7 Search Filter

  1. Use the search filter to find specific ferrules
  2. Enter ferrule name or number
  3. Filter results based on selected platform
  4. Clear filter to view all ferrules for the selected client

5.8 Ferrule Relationship with Parts

Ferrules are closely tied to parts in the system:

  • Each part can have multiple ferrules (e.g., Part A072C004 has 12 ferrules)
  • Ferrules have specific directions (S1, S2, U configurations)
  • Checkpoints are created for each ferrule on a part
  • Quality control inspections focus on individual ferrules

6. Checkpoints Management

6.1 Purpose

The Checkpoints module is the core of the quality control process. It defines specific inspection points for each ferrule on each part. Checkpoints include descriptions, images, and image processing configurations to guide inspectors during the QC process.

6.2 Understanding Checkpoints

A checkpoint represents:

  • A specific inspection point on a ferrule
  • Visual reference through uploaded images
  • Processing instructions for automated inspection
  • Association with specific parts and ferrules
  • Model-specific inspection criteria

6.3 Viewing Checkpoints

  1. Click on Checkpoints from the navigation menu
  2. Select Client from the first dropdown (e.g., Cummins)
  3. Select Part from the second dropdown (e.g., A072C004 - Shakti CT Big)
  4. View checkpoints in the table displaying:
    • Part number and name
    • Ferrules No and Name
    • Checkpoint description
    • Associated image
    • Edit and Delete options
    • Select checkbox
Example Checkpoint Entry:
Part: A072C004
Part Name: Shakti CT Big
Ferrules No: 12
Ferrules Name: Shakti CT Big
Checkpoint: 1
Image: No Image (or image preview shown)

6.4 Adding a Checkpoint

  1. Select the client (platform) from the dropdown
  2. Select specific model codes if applicable
  3. Click the + (Plus) button in the top-left corner
  4. The "Add Checkpoint" dialog will appear
  5. Fill in the checkpoint form:
    • Part: Select from dropdown (auto-populated based on client)
    • Part Name: Auto-filled based on selected part
    • Select a Ferrules: Choose the specific ferrule from dropdown
    • Checkpoint: Enter checkpoint description or identifier
    • Upload Image: Click "Browse..." to select an image file
    • Deselect Checkbox: Use if needed to deselect options
    • Image Processing Type: Select processing type from dropdown
  6. Click Save to create the checkpoint
  7. Click Cancel to discard and close the dialog

6.5 Editing a Checkpoint

  1. Find the checkpoint in the table
  2. Click the Edit button for that checkpoint
  3. The "Edit Checkpoint" dialog will open
  4. Modify checkpoint details:
    • Update Part selection
    • Update Part Name
    • Change Ferrules selection
    • Modify Checkpoint text/description
    • Upload a new image or remove existing one
    • Change Image Processing Type
  5. Click Save to apply changes
  6. Click Cancel to discard changes

6.6 Automatic Checkpoint Updates

The system provides an automatic update feature for efficiently updating checkpoints across multiple models:

  1. Navigate to the Update Checkpoint, img Screen
  2. Select image processing type from dropdown
  3. Select the models you want to apply changes to
  4. Enter checkpoint information
  5. Upload the image
  6. The system will automatically update all parts with associated checkpoints

Bulk Update Benefit

This feature is particularly useful when the same checkpoint needs to be applied to multiple models, saving significant time compared to manual entry for each model.

6.7 Deleting Checkpoints

Single Checkpoint Deletion

  1. Locate the checkpoint you want to delete
  2. Click the Delete button (displayed in red)
  3. Confirm the deletion when prompted

Bulk Checkpoint Deletion

  1. Select multiple checkpoints using the Select checkbox in each row
  2. Click the Delete Selected button at the bottom of the table
  3. Confirm the bulk deletion when prompted
  4. All selected checkpoints will be removed

6.8 Search Functionality

  1. Use the search box labeled "Search Checkpoint..."
  2. Enter search terms to find checkpoints by:
    • Checkpoint number
    • Part name
    • Ferrule name
  3. Click Search to filter results
  4. Note: Images are filtered based on models connected to the selected part

6.9 Image Processing

Checkpoints support image processing for automated quality control:

  • Select appropriate image processing type from dropdown when adding/editing checkpoints
  • Image processing types define how the system analyzes checkpoint images
  • Apply specific processing to designated models
  • Ensure images are clear and properly oriented for accurate processing

Image Quality Tips

  • Upload high-resolution images for best results
  • Ensure proper lighting in checkpoint images
  • Frame the ferrule clearly in the image
  • Use consistent image formats (JPG, PNG recommended)

7. Ferrules Connection

7.1 Purpose

The Ferrules Connection module establishes relationships between ferrules, parts, and specific model codes. This is a critical configuration step that defines which ferrules apply to which models, enabling the system to perform accurate quality control checks.

7.2 Understanding Connections

Connections define:

  • Which ferrules are present on which models
  • The relationship between parts and model variations
  • Quality control scope for each model
  • Inspection requirements per model configuration

7.3 Accessing Ferrules Connection

  1. Click on Ferrules Connection from the navigation menu
  2. You'll see the connection interface with two operational modes:
    • Connect Mode (default) - For creating new connections
    • Copy Mode - For duplicating existing connections

7.4 Connect Mode

Use Connect Mode to establish new ferrule-to-model relationships.

Making Connections

  1. Select Client from the dropdown at the top (e.g., Cummins)
  2. Choose between two connection methods:

Method 1: To Models

  1. Click the To Models button
  2. A model selection interface will appear
  3. Select the specific models you want to connect ferrules to
  4. Choose the relevant ferrules for these models
  5. Click Connect to establish the connection

Method 2: Select Ferrules

  1. Click the Select Ferrules button
  2. Choose specific ferrules from the available list
  3. Select the models these ferrules apply to
  4. Click Connect to link them together

7.5 Copy Mode

Copy Mode is a powerful time-saving feature that allows you to duplicate ferrule connections from one model to another. This is especially useful when setting up similar model configurations.

Copying Connections Between Models

  1. Click the Copy Mode button to switch from Connect Mode
  2. The interface will change to show copy options
  3. Follow these steps to copy connections:
    • Select the model code whose part connection you want to copy from
    • Use the "Copy From" function
    • In the "From Model" section, select the source model code
    • In the "To Model" section, select the destination model code
    • Click the "Copy Data" button
  4. The system will replicate all ferrule connections from the source model to the destination model
  5. Verify the copied connections are correct

Copy Mode Use Cases

  • Setting up multiple similar model variants
  • Creating template configurations
  • Quickly replicating proven configurations
  • Reducing manual data entry errors

7.6 Verification and Management

Verifying Connections

  1. After creating connections, review them carefully
  2. Select the platform and model to view current connections
  3. Check that all required ferrules are connected
  4. Verify no unnecessary connections exist

Modifying Connections

  • To remove a connection, select the model and ferrule, then disconnect
  • To add additional connections, use Connect Mode
  • To replace connections entirely, use Copy Mode from a corrected source model

7.7 Best Practices

  • Always select the platform (client) first before making connections
  • Verify connections before applying to avoid incorrect quality control configurations
  • Use Copy Mode efficiently for similar model setups to save time
  • Double-check connections before proceeding to checkpoint creation
  • Document your connection logic for future reference
  • Test connections with a sample inspection before full deployment

Connection Impact

Ferrule connections directly affect which checkpoints are applied during quality control. Incorrect connections can lead to missed inspections or unnecessary checks. Always verify your connections thoroughly.

10. Important Cautions

Critical Warnings

This section contains critical information about operations that can result in permanent data loss. Please read carefully and follow all recommendations.

10.1 Platform (Client) Deletion

EXTREME CAUTION REQUIRED

Deleting a platform is one of the most destructive operations in the system. This action cannot be undone and will result in massive data loss.

What Gets Deleted

When you delete a platform (client), the following data is permanently deleted:

  • All related serial numbers associated with that platform
  • All connections between models, parts, and ferrules for that platform
  • All parts linked to the platform
  • All checkpoints for those parts
  • All quality control data associated with the platform
  • All historical inspection records for vehicles on that platform

Before Deleting a Platform

  1. Verify with all stakeholders that the platform is no longer needed
  2. Export all reports related to the platform for archival
  3. Document the deletion decision and obtain necessary approvals
  4. Consider archiving instead of deleting (if system supports it)
  5. Back up the database before proceeding
  6. Double-check that you've selected the correct platform
